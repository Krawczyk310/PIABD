PROJEKT: STRONA WYSWIETLAJACA BAZE DANYCH

1. Zainstaluj XAMPP i uruchom Apache oraz MySQL.
2. Skopiuj folder baza-prosta do C:\xampp\htdocs.
3. Wejdz na http://localhost/phpmyadmin
4. Wybierz Import i zaladuj plik database.sql.
5. Otworz http://localhost/baza-prosta/

Strona wyswietla dane z tabeli uczniowie.
Jesli zmienisz dane w phpMyAdmin, strona pokaze aktualna zawartosc bazy.

GitHub:
Utworz repozytorium i wgraj index.php, database.sql oraz README.txt.
GitHub Pages nie uruchamia PHP/MySQL; do uruchomienia strony w internecie potrzebny jest hosting PHP i MySQL.
